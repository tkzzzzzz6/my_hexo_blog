# 小任务与阶段交付检查清单

1. 在阶段 Issue 与子任务中写清问题、范围和可检查的标准。
2. 在隔离的 codex/feature/<topic> 中实现并集成，保留其他工作区。
3. 子任务通过提交记录追踪，默认不单独向 main 提 PR。
4. 集成后运行 lint、行为测试、构建与 feature push CI。
5. 冲突按双方意图解决；全局意图冲突或范围扩大交维护者判断。
6. 阶段完成后只创建一个 main PR，附任务摘要、预览和兼容性证据。
7. 维护者审查当前 SHA；批准后正常合并，不绕过保护。

完整说明见 [阶段交付流程](../agent-workflow.md)。feature 集成不等于网站发布。
