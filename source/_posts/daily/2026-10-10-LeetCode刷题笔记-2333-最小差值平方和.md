[题目链接](https://leetcode.cn/problems/minimum-sum-of-squared-difference/)

对 `nums1` 和 `nums2` 中的元素，分别**至多**执行 $k_1$、$k_2$ 次加一或减一操作，求修改后的最小差值平方和。

## 思路：优先削减最大的差值

设

$$
d_i=|nums1[i]-nums2[i]|,\qquad k=k_1+k_2.
$$

差值为正时，修改任一数组都能让它减小 $1$，因此两份预算可合并，问题变成：至多把差值数组中的元素减小 $k$ 次，最小化 $\sum d_i^2$。差值减到 $0$ 就停止；若 $\sum d_i\le k$，答案直接为 $0$。

将正数 $x$ 减成 $x-1$，平方和的减少量为

$$
x^2-(x-1)^2=2x-1.
$$

$x$ 越大，收益越大，所以每次应削减**当前最大的差值**。

操作次数很大，不能逐次模拟。由于差值不超过 $10^5$，用 `cnt[x]` 记录差值为 $x$ 的元素个数，从大到小按桶处理：

- 每层取 $t=\min(k,cnt[x])$，将 $t$ 个差值从 $x$ 移到 $x-1$，同时扣除 $t$ 次操作。
- 若整桶都能移动，下一层会与原有元素合并；否则操作次数已用完，结束处理。

最后累加各桶对平方和的贡献。

## 代码

```cpp
#include <algorithm>
#include <cstdlib>
#include <vector>
using namespace std;

class Solution {
public:
    long long minSumSquareDiff(vector<int>& nums1, vector<int>& nums2,
                              int k1, int k2) {
        const int U = 100000;
        vector<int> cnt(U + 1);
        long long k = 1LL * k1 + k2, sum = 0;

        for (int i = 0; i < (int)nums1.size(); ++i) {
            int d = abs(nums1[i] - nums2[i]);
            ++cnt[d];
            sum += d;
        }
        if (sum <= k) return 0;

        for (int x = U; x > 0 && k > 0; --x) {
            int t = (int)min(k, 1LL * cnt[x]);
            cnt[x] -= t;
            cnt[x - 1] += t;
            k -= t;
        }

        long long ans = 0;
        for (int x = 1; x <= U; ++x) {
            ans += 1LL * cnt[x] * x * x;
        }
        return ans;
    }
};
```

## 复杂度与边界

设数组长度为 $n$，差值上界 $U=10^5$。

- 时间复杂度：$O(n+U)$。
- 空间复杂度：$O(U)$。

平方和最大可达 $10^{15}$，需要用 `long long`，乘法也要从 `1LL` 开始提升类型。削减循环只处理 $x>0$，不会把零差值继续减成负数。
