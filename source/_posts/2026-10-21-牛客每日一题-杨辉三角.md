## 题目信息

- 平台：牛客
- 题目：杨辉三角
- 难度：简单
- 时间限制：1 秒 / 空间限制：256M

---

## 题目描述

小 F 对杨辉三角颇有研究，他把杨辉三角第 $n$ 行的数提出来，从左到右分别为 $a[0],a[1],\dots,a[n-1]$。

现在他想知道：

$$
\sum_{i=0}^{n-1}i^2\times a[i]
$$

的值是多少，答案对 $99824353$ 取模。

### 输入描述

输入一个正整数 $n$：

$$
n\le 10^{18}
$$

### 输出描述

输出上述式子的值，答案对 $99824353$ 取模。

---

## 初步思路

$n$ 最大达到 $10^{18}$，显然无法建出杨辉三角逐项累加。必须把求和式化成**闭式公式**。

杨辉三角第 $n$ 行的元素就是组合数：

$$
a[i]=\binom{n-1}{i}
$$

于是问题变成计算：

$$
S(n)=\sum_{i=0}^{n-1}i^2\binom{n-1}{i}
$$

这个式子可以用二项式定理处理。

---

## 公式推导

### 方法一：生成函数

由二项式定理：

$$
(1+x)^{n-1}=\sum_{i=0}^{n-1}\binom{n-1}{i}x^i
$$

对上式求一次导再求一次导，并代入 $x=1$：

**第一次求导：**

$$
(n-1)(1+x)^{n-2}=\sum_{i=1}^{n-1}i\binom{n-1}{i}x^{i-1}
$$

**第二次求导：**

$$
(n-1)(n-2)(1+x)^{n-3}=\sum_{i=2}^{n-1}i(i-1)\binom{n-1}{i}x^{i-2}
$$

令 $x=1$ 得：

$$
\sum_{i=0}^{n-1}i(i-1)\binom{n-1}{i}=(n-1)(n-2)2^{n-3}
$$

又因为：

$$
i^2=i(i-1)+i
$$

所以：

$$
S(n)=\sum i(i-1)\binom{n-1}{i}+\sum i\binom{n-1}{i}
$$

其中：

$$
\sum_{i=0}^{n-1}i\binom{n-1}{i}=(n-1)2^{n-2}
$$

两者相加：

$$
\begin{aligned}
S(n)&=(n-1)(n-2)2^{n-3}+(n-1)2^{n-2}\\
&=(n-1)2^{n-3}\big[(n-2)+2\big]\\
&=\boxed{n(n-1)2^{n-3}}
\end{aligned}
$$

### 方法二：组合恒等式

也可以直接用组合数递推。注意到：

$$
i\binom{n-1}{i}=(n-1)\binom{n-2}{i-1}
$$

以及：

$$
i^2\binom{n-1}{i}=i(n-1)\binom{n-2}{i-1}
$$

利用 $\sum_{j}\binom{m}{j}j=x\cdot2^{m-1}$ 同理可得相同结论，这里不再展开。

> [!note]
> 当 $n=1$ 时 $S(1)=0$，公式中的 $2^{n-3}=2^{-2}$ 没有意义，因此代码中单独特判 $n=1$。$n=2$ 时公式成立，结果为 $1$。

---

## 算法分析

- 核心：组合数求和化为闭式公式；
- 关键技巧：二项式定理求导，提取 $i^2=i(i-1)+i$；
- 整数除法：先取模再乘以 $2$ 的逆元；
- 时间复杂度：$O(\log n)$，来自快速幂；
- 空间复杂度：$O(1)$。

### 关于除以 2

公式中的 $n(n-1)/2$ 在取模意义下不能直接整除。注意到模数 $P=99824353$ 是奇数，因此 $2$ 的逆元存在：

$$
2^{-1}\equiv\frac{P+1}{2}\pmod P
$$

所以：

$$
\frac{n(n-1)}{2}\equiv n(n-1)\times\frac{P+1}{2}\pmod P
$$

同时，为避免 $n(n-1)$ 溢出（$n$ 可达 $10^{18}$），要先对两个因子分别取模再相乘。

## 代码实现

以下给出 C++、Python、Java、Go、Rust 五种语言的实现，逻辑完全一致。切换上方的标签即可对比。

```cpp
#include <iostream>

using namespace std;

using ll = long long;

const ll MOD = 99824353;

// 快速幂：计算 b^e mod MOD
ll qpow(ll b, ll e) {
    ll result = 1;
    b %= MOD;

    while (e > 0) {
        if (e & 1) {
            result = result * b % MOD;
        }
        b = b * b % MOD;
        e >>= 1;
    }

    return result;
}

int main() {
    ll n;
    cin >> n;

    // 第 1 行只有 a[0] = 1，对答案没有贡献
    if (n == 1) {
        cout << 0 << '\n';
        return 0;
    }

    // 答案为 n * (n - 1) / 2 * 2^(n - 2) mod MOD
    // 先取模再乘，避免 n * (n - 1) 溢出
    ll a = (n % MOD) * ((n - 1) % MOD) % MOD;
    ll b = a * qpow(2, n - 2) % MOD;

    // 模数为奇数时，除以 2 等价于乘以 2 的逆元
    cout << b * ((MOD + 1) / 2) % MOD << '\n';

    return 0;
}
```

## 样例验证

$n=3$ 时第 3 行为 $1,2,1$：

$$
0^2\times1+1^2\times2+2^2\times1=0+2+4=6
$$

与公式计算结果一致。

$n=10$ 时第 10 行为 $1,9,36,84,126,126,84,36,9,1$：

$$
\sum i^2a[i]=11520
$$

与公式结果一致。

---

## 易错点

1. **模意义下不能直接除以 2**：必须乘以逆元 $(P+1)/2$。
2. **先取模再相乘**：$n$ 可达 $10^{18}$，直接算 $n(n-1)$ 会溢出 `long long`。
3. **$n=1$ 需要特判**：此时求和只有一项 $0^2\times1=0$，而公式含 $2^{-2}$ 无意义。
4. **组合数是第 $n-1$ 行**：杨辉三角第 $n$ 行对应 $\binom{n-1}{i}$，不要写成 $\binom{n}{i}$。
5. **快速幂的指数是 $n-2$**：来自 $2^{n-3}\times2=2^{n-2}$。

---

## 总结

本题的关键是把「杨辉三角逐项求和」转化为「组合数加权求和」，再用二项式定理的两次求导得到闭式公式：

$$
\sum_{i=0}^{n-1}i^2\binom{n-1}{i}=n(n-1)2^{n-3}
$$

转化完成后，只需一次快速幂即可在 $O(\log n)$ 时间内求出答案。
