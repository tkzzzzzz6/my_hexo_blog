## 题目描述

开始时有 $n$ 颗石子。每次操作需要选择正整数 $a,b$，满足：

$$
a>1,\qquad n=a\times b
$$

然后收回其中一整行石子，手中的石子数变为 $b$。也就是说，每次操作都可以把当前数字变成它的一个真因子。

当石子数变为 $1$ 时游戏结束。设操作过程中的状态为：

$$
c_1=n,c_2,c_3,\dots,c_k=1$$

游戏得分为：

$$
\sum_{i=1}^{k}c_i
$$

请计算最优策略下的最大得分。

### 输入描述

输入一个整数 $n$：

$$
2\le n\le 10^9
$$

### 输出描述

输出一个整数，表示最大得分。

---

## 初步思路

每次操作本质上是选择当前数的一个真因子作为下一个状态。我们希望：

1. 尽可能保留较大的中间状态；
2. 同时尽可能增加操作次数，让更多状态参与求和。

例如 $n=10$：

- 直接选择 $b=2$：$10\to2\to1$，得分为 $13$；
- 选择 $b=5$：$10\to5\to1$，得分为 $16$。

因此，不能简单地选择最小因子作为下一个状态，而要从整体序列的角度考虑。

---

## 关键结论一：每次最好只除以一个质因数

假设某一步从 $x$ 直接变成 $x/(ab)$，其中 $a,b>1$。我们可以把它拆成两步：

$$
x\to\frac{x}{a}\to\frac{x}{ab}
$$

相比直接跳过去，拆分后额外增加了一个正数状态 $x/a$，因此总得分一定更大。

所以最优方案中，每次操作都应该只除以一个质数。也就是说，如果：

$$
n=p_1p_2\cdots p_m
$$

那么最优过程应该依次除掉这些质因数，最终得到 $1$。

---

## 关键结论二：质因数应该从小到大使用

考虑两个相邻的质因数 $a,b$，当前剩余部分为 $x$。

如果先除以 $a$，状态会经过：

$$
xab\to xb\to x
$$

如果先除以 $b$，状态会经过：

$$
xab\to xa\to x
$$

两种方案的差别只有中间状态：

- 先除以 $a$，中间得到 $xb$；
- 先除以 $b$，中间得到 $xa$。

为了让中间状态更大，应当让 $b$ 更大，也就是先除以较小的质因数 $a$。

因此，质因数应当按照**从小到大**的顺序依次除掉。

这也等价于：每次寻找当前数的最小质因子并除掉它。

---

## 算法流程

1. 将答案初始化为 $n$，因为初始状态也计入得分。
2. 从 $2$ 开始试除当前的 $n$。
3. 如果 $i$ 是当前 $n$ 的因子：
   - 执行 `n /= i`；
   - 将新的 $n$ 加入答案；
   - 继续使用同一个 $i$，因为最小质因子可能出现多次。
4. 如果 $i$ 不是因子，则令 $i++$。
5. 循环结束后，如果剩余的 $n>1$，它一定是一个质数，最后还需要执行一次 $n\to1$，因此答案加 $1$。

### 样例：$n=10$

$$
10=2\times5
$$

依次除以最小质因数：

$$
10\to5\to1
$$

得分为：

$$
10+5+1=16
$$

### 样例：$n=8$

$$
8=2\times2\times2
$$

依次除以 $2$：

$$
8\to4\to2\to1
$$

得分为：

$$
8+4+2+1=15
$$

---

## 算法分析

- 核心：质因数分解 + 贪心；
- 贪心策略：每次除以当前数的最小质因子；
- 时间复杂度：$O(\sqrt n)$；
- 空间复杂度：$O(1)$。

由于 $n\le10^9$，试除到 $\sqrt n$ 的复杂度可以满足要求。

## 代码实现

```cpp
#include <bits/stdc++.h>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n;
    cin >> n;

    long long answer = n;

    for (long long factor = 2; factor * factor <= n; ) {
        if (n % factor == 0) {
            n /= factor;
            answer += n;
        } else {
            ++factor;
        }
    }

    if (n > 1) {
        answer += 1;
    }

    cout << answer << '\n';

    return 0;
}
```

## 易错点

1. **不能只进行一次质因数试除**：例如 $8$ 需要连续除以 $2$ 三次。
2. **因子命中后不能立即递增**：当前质因数可能重复出现，应该继续使用同一个因子。
3. **剩余的大于 $1$ 的数需要额外加 $1$**：循环结束时剩余数一定是质数，最后还要从它变成 $1$。
4. **答案使用 `long long`**：虽然 $n\le10^9$，但整个得分由多个状态累加，使用 64 位整数更稳妥。
5. **`factor * factor <= n` 是动态条件**：每次除法后 $n$ 变小，循环上界也会随之缩小。

---

## 可改进点

- 当 $n$ 更大（例如 $10^{12}$ 或 $10^{18}$）时，$O(\sqrt n)$ 试除可能过慢，可以先做一步 Pollard-Rho 质因数分解，再按相同贪心策略处理。
- 输入若只有单组数据，五种语言的 `t` 处理都可以简化。
- 如果 $n$ 是质数，答案就是 $n + 1$，可以特判减少一次循环。

---

## 总结

本题看起来是在因数之间进行选择，实际上可以通过两个结论直接确定最优策略：

1. 复合因数拆成多个质因数逐步处理，可以增加中间状态，因此更优；
2. 相邻质因数中，较小的质因数应该先被除掉，这样中间状态更大。

所以只需要不断除以当前数的最小质因子，并把每次得到的新数累加到答案中即可。
